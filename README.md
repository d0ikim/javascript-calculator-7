# 문자열 덧셈 계산기

## 기능 목록

### 입력 기능

- [x] 구분자(, :)와 양수로 구성된 문자열을 입력받는다.
  - [ ] 잘못된 값을 입력한 경우, "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 프로그램 종료. 잘못된 값의 경우는
    - [x] 구분자가 없는 경우
    - [ ] 음수를 입력한 경우
  - [ ] 커스텀 구분자(//와\n 사이에 위치하는 문자)를 지정한 경우
    - [ ] 잘못된 값을 입력한 경우, "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 프로그램 종료. 잘못된 값의 경우는
      - [ ] 커스텀 구분자가 여러개인 경우

### 출력 기능

- [ ] 덧셈 결과를 출력한다.

### 핵심 기능

- [x] 구분자를 기준으로 숫자들을 분리한다.
- [ ] 각 숫자들의 합을 계산해 반환한다.
